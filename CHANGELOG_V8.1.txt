TIMESTAMP GENERATOR V8.1
========================

Perubahan utama:
1. Mode baru: Batch Manual.
   - Upload banyak foto bernama 1, 2, 3, dst.
   - Input koordinat dan daerah secara manual.
   - Atur tanggal, jam mulai, jam selesai, dan zona waktu.
   - Jam dibuat random tetapi tetap berurutan sesuai urutan file.

2. Batch Manual memakai pola input yang mirip Batch NPSN Online.
   - Flow: upload foto -> input lokasi -> atur rentang jam -> atur gaya -> generate batch.
   - Bisa atur ukuran timestamp, bold, dan variasi koordinat kecil per foto.
   - Bisa menambahkan baris tambahan opsional yang akan diterapkan ke semua foto batch.

3. Mode aplikasi sekarang menjadi:
   - Satu Foto
   - Batch Manual
   - Batch NPSN Online

4. Output Batch Manual:
   - ZIP semua foto hasil timestamp
   - timestamp_log.csv
